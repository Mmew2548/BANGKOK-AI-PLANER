# Bangkok AI Travel Planner (Streamlit)
1. `python -m venv .venv && source .venv/bin/activate` (Windows: `.venv\Scripts\activate`)
2. `pip install -r requirements.txt`
3. คัดลอก `.env.example` เป็น `.env` แล้วใส่ GOOGLE_MAPS_API_KEY
4. เปิดใช้ใน Google Cloud: Routes API, Maps Embed API
5. `streamlit run app.py`

แก้ราคาได้ที่ `fares.py`
